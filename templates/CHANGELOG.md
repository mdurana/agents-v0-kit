# Changelog

All notable changes to this project are recorded here. The format follows Keep a Changelog; versions follow semantic versioning (a breaking contract change is major, a feature minor, a fix patch).

`sh .agents-v0/scripts/release-notes.sh <milestone manifest or requirements artifact> --insert CHANGELOG.md` adds the stories whose release is approved under `[Unreleased]`. The release owner picks the version, renames `[Unreleased]` to it, and tags.
